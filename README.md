# CI更好的内存优化

ClassIsland 2.x 插件，基于 .NET 8 和 ClassIsland Plugin SDK。设置页提供优化开关、运行间隔、托管堆阈值、Windows 工作集修剪选项及激进模式。

## 重要限制

- .NET 垃圾回收只能释放不再被引用的托管对象，无法清除仍在使用的缓存或强制优化 ClassIsland/其他插件的代码。
- Windows 工作集修剪只针对 ClassIsland 当前进程，主要影响驻留内存；操作系统可能立即重新调入页面。不会终止或修改其他应用。
- 插件不能保证内存减少 1/4～1/2，也不能保证降低 CPU 占用。强制 GC 本身可能增加 CPU 使用和卡顿。
- 激进模式最多每 5 分钟检查一次，并且仅在托管堆达到设置阈值时进行阻塞式压缩回收；仍可能造成卡顿、CPU 突增、页面重载、崩溃或退出。修剪工作集后的内存可能很快回升。每次 ClassIsland 启动都需要重新确认。非必要不要开启。上课时建议同时使用 ClassIsland 教学安全模式，但不保证防止故障。
- 首次打开插件设置页时会依次弹出《用户协议》《隐私协议》《免责声明》。拒绝任一协议时，优化保持关闭；之后可从本插件设置页重新查看并同意。
- 协议全文随插件包放在 `Agreements` 目录中。插件不主动联网或上传遥测。

## 构建与打包

安装 .NET 8 SDK 后，在此目录运行：

```powershell
dotnet publish -p:CreateCipx=true
```

ClassIsland Plugin SDK 会在 `cipx` 目录生成 `.cipx` 包和校验信息。SDK 版本和打包属性参照 ClassIsland 官方示例插件与插件发布文档。
