版本：1.2

1. 本插件是供 ClassIsland 使用的社区插件，不是 ClassIsland 官方组件。安装、开启或使用插件即表示你已阅读并同意本协议、隐私协议及免责声明；不同意时请勿启用优化，并可卸载插件。
2. 插件只对 ClassIsland 自身执行 .NET 垃圾回收，并可按设置尝试修剪 ClassIsland 自身的 Windows 工作集。它不会结束或调整其他应用，也不承诺降低任何固定比例的内存或 CPU 占用。
3. 你可以在 ClassIsland 设置中关闭优化、修改检查间隔和托管堆阈值、切换工作集修剪，或随时关闭激进模式。激进模式只在当前运行期间有效，并要求每次开启时确认风险。
4. 请勿在未保存重要工作或正在授课时测试激进模式。建议教学场景使用 ClassIsland 教学安全模式，但该模式不能保证避免插件引起的问题。
