# 隐私协议

版本：1.2

1. 插件不主动连接网络，不上传遥测、使用数据或个人信息，也不读取其他进程的内存。
2. 插件设置（优化开关、工作集选项、间隔、阈值及协议版本）保存在 ClassIsland 为本插件分配的本地配置目录中。是否保留、备份或删除该目录由 ClassIsland 的管理方式决定。
3. 运行时只读取 ClassIsland 自身的 .NET 堆大小作为是否执行温和回收的判断依据；Windows 工作集功能也只对 ClassIsland 当前进程调用系统 API。
4. 发生配置读写或系统调用错误时，插件可能在 ClassIsland 日志中写入错误信息。错误记录不包含用户主动输入的内容；本插件没有单独的远程日志收集功能。
5. 卸载插件前，你可以通过 ClassIsland 的插件管理界面卸载。设置文件可能依照 ClassIsland 的卸载策略保留或移除。
